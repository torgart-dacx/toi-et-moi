# Toi et Moi — вселенная стихов

Интерактивный 3D-сайт для сборника «Toi et Moi» (Торгашев Артём, Ереван 2025).
Путешествие по вихрю, закрученному вверх, — от вступительного стиха к послесловию.
21 стих на пергаментных листах (французский оригинал и русский перевод рядом), фотографии
из сборника на листах и их эскизы вокруг, рисунки тушью, приглушённые свечи, перья,
лепестки и пух, которые подхватывают порывы ветра. Пять глав со своим цветом неба
и своей музыкой: тепло, тоска, гнев с кульминацией на «Шипах и розах», надежда,
меланхоличный финал. В конце — посвящение в центре вихря и финальная сцена: листы
слетаются к читателю и кружатся вихрем, камера делает оборот и поднимает взгляд в небо, где кружат буквы
стихов, все листы улетают вверх и ярко сгорают от края, под романтичную тему со скрипкой; пепел складывается
в рисунок обложки — из него проступают обложка книги и первый стих при тусклых
свечах, с кнопками «Нравится» и «Поделиться». Оглавление с поиском, полноэкранный режим.

Посмотреть локально можно двойным кликом по `index.html`: сайт работает без интернета.

## Как выложить на GitHub Pages (≈5 минут)

1. Зайдите на github.com → **New repository** → имя, например, `toi-et-moi`. Выберите **Public** и нажмите **Create repository**.
2. В новом репозитории нажмите **uploading an existing file** (или **Add file → Upload files**).
   Перетащите туда **всё содержимое этой папки**: `index.html`, `app.js`, `.nojekyll`, `README.md`, `package.json`
   и папки `css`, `fonts`, `img`, `js`. Нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В **Source** выберите **Deploy from a branch**,
   затем ветку **main** и папку **/ (root)**. Нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/toi-et-moi/`.

Для работы сайта нужны `index.html`, `app.js`, `css/`, `fonts/` и `img/`. Папка `js/` — исходники, из которых собран `app.js`.

## Кнопки «Нравится» и «Поделиться»

«Поделиться» открывает системное меню телефона, а на компьютере — Telegram, ВКонтакте, WhatsApp
и копирование ссылки. После публикации впишите адрес сайта в `index.html`:
`<meta property="og:url" content="https://<ваш-логин>.github.io/toi-et-moi/">` — тогда кнопка всегда
будет делиться правильной ссылкой (пересобирать сайт не нужно).

Карточка ссылки (картинка при отправке в Telegram, WhatsApp, ВКонтакте) — файл `img/og.jpg`.
Мессенджеры берут её только по полному адресу, поэтому там же замените
`<meta property="og:image" content="img/og.jpg">` на
`<meta property="og:image" content="https://<ваш-логин>.github.io/toi-et-moi/img/og.jpg">`.
Telegram запоминает карточку: если ссылку уже отправляли до этой правки, обновить её можно через бота @WebpageBot.

«Нравится» запоминает отметку в браузере читателя. Общий счётчик лайков от всех читателей требует
небольшого сервера (GitHub Pages хранит только файлы) — его можно подключить отдельно.

## Управление

- Путешествие начинается с вступительного стиха «Je me souviens plus du nom de la fleur».
- Колесо мыши, свайп, `↓` или пробел — сначала прокручивают длинный стих, затем ведут к следующему; `→` `←` — сразу к следующему или предыдущему.
- `F` или кнопка ⛶ — полный экран (включается сам при «Начать»). На iPhone полный экран браузер не даёт — можно «Поделиться → На экран „Домой“» и открывать оттуда.
- Интерфейс прячется, пока вы читаете и листаете; пошевелите мышью или коснитесь экрана, чтобы он появился.
- «Карта» (или `Esc`) — весь вихрь целиком: он вращается, по спирали течёт поток света, его можно крутить и приближать, клик по огоньку — перелёт к стиху.
- На карте камера свободная: колесо летит к точке под курсором (без замедления у цели), перетаскивание вращает, правая кнопка сдвигает, `W A S D` — полёт, `Q`/`E` — вниз/вверх, `Shift` — быстрее. Пока вы двигаетесь, вихрь не крутит камеру; вращение возвращается через ~14 секунд покоя.
- «Начать заново» в финале возвращает на карту ко всему вихрю.
- `/` — поиск по строкам на обоих языках.
- На телефоне листы стоят друг над другом, кнопка «Перевод →» переключает оригинал и перевод.
- Сайт сам снижает разрешение картинки, если устройство не успевает, поэтому движение остаётся плавным.

## Прогулка, голос и фотографии

- **Прогулка** — кнопка «Прогулка» (вверху или на карте): стихи сами сменяют друг друга, длинные плавно прокручиваются. Любое действие останавливает прогулку; после посвящения начинается финал.
- **Голос автора** — сейчас выключен. Чтобы включить: положите обработанные `mp3` в `voice/` и пропишите их в `voice/voices.json`, например `{ "sevan": { "ru": "sevan-ru.mp3" } }` (ключ — id стиха, `fr` / `ru` — язык). Тогда у стиха появится кнопка «Слушать», а «Прогулка» будет читать голосом.
- **Ожившие фотографии** — клик по фото на листе: эскиз тушью проявляется в фотографию, она медленно дышит и следует за курсором.

## Как поправить текст или цвета

Тексты и цвета галактик лежат в `js/data.js`. После правки сайт нужно пересобрать (нужен Node.js):

```
npm install
npm run build
```

Команда обновит `app.js`. Потом загрузите новый `app.js` на GitHub.

Тексты перенесены из PDF как в книге, авторская орфография сохранена.
